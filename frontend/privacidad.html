1. Responsable y contacto

2. Información que se procesa

  • Datos técnicos de la sesión: el navegador genera un identificador privado que se guarda en el almacenamiento local del navegador (localStorage) para asociar las cargas a una sesión.
  • Datos de archivos: nombre de archivo, tamaño, tipo de contenido, identificador interno, fecha de carga y datos técnicos necesarios para gestionar la transferencia.
  • Contenido: los archivos se envían desde el navegador directamente al almacenamiento Cloudflare R2 mediante URLs firmadas. La API alojada en Render coordina la creación de esas URLs y las operaciones de listado y descarga; no actúa como proxy del contenido binario.
  • Datos de navegación: los proveedores de infraestructura pueden procesar registros técnicos, como dirección IP, fecha, navegador y solicitudes, conforme a sus propias políticas y configuraciones.

3. Finalidades

La información se utiliza para crear y mantener sesiones, cargar y localizar archivos, generar enlaces temporales de descarga, proteger la operación, diagnosticar errores y responder consultas de soporte.

4. Proveedores tecnológicos

El servicio utiliza Netlify para publicar el sitio, Render para ejecutar la API y Cloudflare R2 para almacenar los archivos. Estos proveedores intervienen en la prestación técnica del servicio y pueden tratar datos desde la infraestructura que operan. Sus condiciones y políticas también pueden resultar aplicables a los tratamientos que realizan como proveedores.

5. Acceso a los archivos y seguridad

Los archivos se almacenan en un bucket privado y se entregan mediante enlaces firmados con vencimiento técnico de 24 horas. El vencimiento del enlace no elimina el archivo. La posesión de un enlace válido permite descargar el archivo mientras esté vigente. El token de sesión se guarda en el navegador del usuario; cualquier persona con acceso a ese perfil de navegador puede utilizar la sesión. No existe actualmente un sistema de cuentas personales ni una función de revocación individual de enlaces.

6. Conservación y eliminación

La versión actual no implementa una eliminación automática por antigüedad ni un botón de borrado para el usuario. Por tanto, no debe asumirse que los archivos se eliminan al vencer el enlace. Para solicitar la eliminación de un archivo o realizar una consulta sobre conservación, escribir a ventasonline_24@outlook.com e incluir información suficiente para identificar la carga, sin enviar contraseñas ni datos sensibles innecesarios. La solicitud será revisada y gestionada manualmente cuando sea técnicamente posible.

7. Derechos de las personas

Las personas pueden solicitar información sobre sus datos y, cuando corresponda, ejercer los derechos de acceso, rectificación, actualización, inclusión o supresión mediante el correo de contacto. La solicitud debe permitir identificar razonablemente al solicitante y los datos involucrados. Se responderá conforme a los plazos y requisitos de la normativa uruguaya aplicable.

8. Cambios

Esta política podrá actualizarse cuando cambien las funciones, proveedores o prácticas de tratamiento. La versión vigente se publicará en esta página con su fecha de actualización.
