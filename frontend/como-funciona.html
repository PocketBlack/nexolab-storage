Cómo funciona

Transferencia de archivos en calidad original

NexoLab Storage facilita el envío de archivos pesados entre dispositivos, especialmente en flujos de trabajo de creadores, fotógrafos, videógrafos, agencias y marcas.

1. Selecciona tus archivos

Desde el navegador, selecciona uno o varios archivos para iniciar la carga. La interfaz muestra el avance de la transferencia.

2. Carga directa al almacenamiento

El navegador envía los datos directamente a Cloudflare R2 mediante una URL de carga firmada. La API de NexoLab Storage coordina la autorización técnica, pero no retransmite el contenido binario de los archivos.

3. Comparte el enlace o código QR

Al finalizar, el servicio permite compartir un enlace de descarga o utilizar el código QR disponible en la interfaz.

4. Descarga el archivo

El destinatario abre el enlace y descarga el archivo. Los enlaces firmados de descarga tienen una vigencia técnica de 24 horas. El vencimiento del enlace no significa que el archivo se elimine automáticamente del almacenamiento.

Privacidad y recomendaciones

La sesión privada se identifica mediante un token guardado en el navegador. No hay actualmente cuentas de usuario ni recuperación de sesión entre navegadores. Comparte enlaces solo con personas de confianza y conserva siempre una copia propia de tus archivos. No utilices el servicio como único respaldo ni cargues información sensible o confidencial.
